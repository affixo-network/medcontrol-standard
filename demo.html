Affixo MedControl Standard Demo

Контроль приёма препаратов без путаницы, пропусков и лишних действий

MedControl Standard — это простая 3-страничная система: сначала ввод данных, затем чистое табло текущих задач, затем отдельная страница фиксации действий.

Начать работу Посмотреть табло Открыть принятие Открыть настройки

Для кого это

  • для личного контроля приёма препаратов
  • для семьи и сопровождения близкого человека
  • для ежедневной работы, где важны простота, точность и ясность

Как это работает

1. Ввод
Все строки препаратов, активен / пассивен, расписание, продление и история изменений строки.
2. Табло
Только активные и только незакрытые задачи на сегодня. Без перегрузки и без лишних кнопок.
3. Принятие
Принял, Отменить, Исправить, фактическая дата и время действия, история приёма.

Почему это удобно

  • одна строка = один препарат
  • на первой странице видны все строки, на второй и третьей — только активные
  • после нажатия «Принял» слот исчезает с табло
  • история строки и история приёма разделены и не мешают интерфейсу
  • дата и время фиксируются автоматически
  • название препарата и custom dose можно вводить на любом языке

Главный принцип

Вместо хаоса из записей, напоминаний и устных уточнений пользователь получает одну понятную систему: ввод, текущее табло и отдельную страницу действий.
