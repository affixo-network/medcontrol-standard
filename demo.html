Affixo MedControl Standard Demo

Контроль приёма препаратов без путаницы

MedControl Standard — это простая 3-страничная система: ввод данных, онлайн-табло и страница фиксации приёма.

Открыть приложение Открыть табло Открыть принятие Открыть настройки

Что получает пользователь

  • 1-я страница: ввод всех строк препаратов, активен / пассивен, расписание, продление, история строки.
  • 2-я страница: только активные и только незакрытые задачи на сегодня.
  • 3-я страница: Принял, Отменить, Исправить, фактическая дата и время действия, история приёма.

Ключевая логика

  • Одна строка = один препарат.
  • На 1-й странице видны все строки, на 2-й и 3-й — только активные.
  • После «Принял» слот исчезает с табло.
  • Название препарата и custom dose можно вводить на любом языке.

Для кого это

  • для личного контроля приёма
  • для семейного сопровождения
  • для простой и понятной ежедневной работы без перегрузки интерфейса
