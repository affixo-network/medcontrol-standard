# Affixo MedControl Standard — Final Sales-Ready Build

Состав пакета:
- index.html — коммерческая точка входа / демо-страница
- input.html — ввод и редактирование препаратов
- dashboard.html — табло задач на сегодня
- action.html — фиксация приема
- settings.html — настройки профиля и региона
- core.js — единая логика интерфейса

Что улучшено:
- исправлена архитектура страниц, action вынесен в отдельную полноценную страницу;
- добавлены поиск и фильтрация в реестре препаратов;
- усилена валидация слотов, дат, повторов и режимов;
- исправлена обработка локальной даты без ошибок UTC-сдвига;
- добавлена ручная коррекция фактического времени приема;
- добавлены история строк, история приема и комментарии;
- улучшены визуальная и коммерческая упаковка для демо;
- добавлен понятный medical disclaimer.

Как показывать клиенту:
1. Открыть index.html.
2. Перейти в input.html и показать создание строки.
3. Перейти в dashboard.html и показать контроль задач.
4. Перейти в action.html и показать фиксацию приема и коррекцию времени.
5. Перейти в settings.html и показать профиль пациента.
6. При необходимости нажать Reset demo.

Ограничения текущего режима Standard:
- single-user;
- локальное хранение в браузере;
- без серверной синхронизации и командного доступа.
